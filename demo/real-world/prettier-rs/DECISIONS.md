# Decisions: Prettier to Rust

Original: Prettier 3.6.2 (tag 3.6.2, commit 7a8b05f41574633fd3af5298f3eeaf33567ad3d3), built with
`yarn build --no-minify` and copied to `node_modules/prettier` of this app folder.

## ADR-001: Headline number is the share of cases answered fully in Rust
Status: accepted (2026-11-18)
Context: "X% of Prettier runs in Rust" needs one measured number.
Decision: the fallback rate of the front door over the recorded CLI cases; every case is replayed
byte-for-byte. Also reported: gate per unit, share of the JS printer's lines ported.
Consequences: a file counts only when Rust formats all of it.

## ADR-002: Whole-file fallback, oxc for parsing
Status: accepted (2026-11-18)
Context: Prettier's own oxc plugin gives byte-identical output on 1,351/1,351 fixtures oxc parses.
Decision: the front door parses with `oxc_parser`, prints with ported Prettier code, and hands the
whole file to Prettier when any node or option is not ported yet.
Consequences: no mixed Rust/JS output inside one file.

## ADR-003: Port Prettier's code, no third-party formatter
Status: accepted (2026-11-18)
Decision: no `oxc_formatter` or `biome_js_formatter` dependency.

## ADR-004: Corpus
Status: accepted (2026-11-18)
Decision: `tests/format/{js,jsx,typescript}` (1,525 files) through `--stdin-filepath`, with the
first option set of each folder's `format.test.js`; 200 of them again with print width 40 and 120,
tabs, no semicolons, single quotes, trailing commas off; vercel/ms 3.0.0-canary.1 (1304f15),
Fuse.js v7.1.0 (8119c18), json-server v1.0.0-beta.3 (6aa56d9). Generated by
`scripts/gen-inputs.mjs`; 300 trap cases from the tool.

## ADR-005: Comments come later
Status: accepted (2026-11-18)
Decision: files with comments stay on Prettier until comment attachment and the JS comment
handlers are ported.

## ADR-006: Equivalence bar
Status: accepted (2026-11-18)
Decision: byte-identical stdout, stderr and exit code. Errors stay on Prettier.

## ADR-007: Units with gate
Status: accepted (2026-11-18)
Decision: doc printer (`printDocToString`), then string/number/width utilities, then a JS printer
unit that grows one node type at a time.

## ADR-008: Checkpoints
Status: accepted (2026-11-18)
Decision: stop after the front door at 100% fallback, after the doc printer passes gate, after the
first JS subset is wired.
